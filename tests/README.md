# Test Suite

This directory contains integration and end-to-end tests for the platform.

- **Backend Unit & API Tests**: Located in `backend/tests/` (run with `pytest backend/tests`).
- **Module Specific Tests**: Each module developer can place tests in `backend/app/modules/<module>/tests/` or in `backend/tests/`.
- **Frontend Verification**: Run `npm run build` in `frontend/`.
